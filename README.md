# 考公学习系统

在线地址：**https://ellis-ovo.github.io/kaogong/**
（GitHub Pages 托管，`main` 分支根目录；改完推上去，一两分钟后自动生效。仓库：`Ellis-ovo/kaogong`）

两个页面，一套东西：

- `index.html` —— 产品介绍页（纵向全屏分栏，白/浅灰/黑三档底色 + 苹果蓝）
- `app.html` —— 真正能用的学习工作台（七大视图，数据存 localStorage）

纯静态，双击打开即可，无需构建、无需联网、无需后端。

### 数据

全部存在浏览器 `localStorage`，键名 `kg-app-v1`，结构：

```js
{
  answers:  { qid: { pick, ok, t } },   // 行测作答
  wrong:    { qid: { n, kind, t } },    // 错题本与错因
  essays:   { eid: { score, chars, t } },
  saved:    [ 时政下标 ],
  iv:       [ { id, q, type, score, used, t } ],
  tasks:    { '2026-11-23': { t1: true } },
  days:     { '2026-11-23': 35 }        // 当日投入分钟数
}
```

换浏览器/清缓存即等于重置；数据看板里也有「清空全部记录」。

### 申论批改的打分口径

不是黑盒打分，四项相加：

- 采分点覆盖：命中关键词的权重占比 × 72（比对前会去掉空白和各类引号，答题时用「」还是“”不影响命中）
- 篇幅：达到字数上限的 50%/80%/100% 分别给 3/9/12 分（超太多扣 5 分）
- 分条结构：出现「一是/二是/首先/其次/第一/其一」给 8 分，否则 2 分
- 最终夹在 18–96 之间，并给出 一类文（80+）/ 二类文（60–79）/ 三类文（40–59）/ 四类文（<40）分档

### 题库是「生成」出来的

手写不可能写到 5000 题，所以行测大题库是**确定性生成器**在浏览器里现算的：
每个生成器用固定种子（mulberry32）产出题目，答案由代码算出来，不依赖网络、不依赖服务端。
刷新页面题目不会变；改 `assets/gen.js` 里的种子就会换一批。
生成题只用于刷手感与考点覆盖，**真实真题仍然是最好的材料**，遇到解析牵强的题可以直接跳过。

规则引擎与生成器都是纯前端，`localStorage` 存进度，不联网、不上传。
想加词条：改 `assets/engine.js` 的 `DICT` / `SHELL`，刷新即可。

## 四、说明

行测题、申论范文、面试题为演示用自编内容，按真题体例编写，不是真题原文（申论范文已按考场格式排版并达到题目字数要求，可作结构参考，但不宜整段背诵）；**时政素材为真实案例**，每条正文的数据与机构名来自所列来源页面，可点链接核对；
不接后端，没有账号体系；页面不设任何付费入口。

## 申论范文三档对照

每题「看范文」里分低分卷（约 38）、中等卷（约 66）、高分卷（约 90）三档，用的**同一道题、同一套采分点**：
差别只在覆盖几条、有没有分条、语言是否规范。三档下方直接标出采分点覆盖数、字数和估分，方便横向比差距。
数据由 `assets/essay-levels.js` 在运行时从各题采分点派生，不额外存储。

## 模考的严格计时

- 开考即写 `S.run`（含题数组、用卷、开始时间、已涂卡），**刷新、切视图都不停表**
- 关掉页面再打开，只要没到点就接着考；已过点则直接判卷并标「超时自动交卷」
- 交卷页对超时卷提示「未作答的题按错误计分」
- 答题卡是机读卡样式：按部分分组、题号 + A B C D 气泡，点字母填涂、再点取消，涂完不跳页
